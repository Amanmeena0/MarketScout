# MarketScout Product Requirements Document (PRD)

## Overview
MarketScout is a multi-agent AI research platform designed to produce high-quality market research reports using a collection of specialized agents.

## Core Principles
1. Think Before Acting
2. Tool First
3. Small Context
4. Structured Outputs

## Supported Analysis Types
1. Industry Analysis (INDUSTRY_ANALYSIS)
2. Barrier Assessment (BARRIER_ANALYSIS)
3. Competitive Analysis (COMPETITOR_ANALYSIS)
4. Market Gap Analysis (MARKET_GAP_ANALYSIS)
5. Sales Forecasting (SALES_FORECASTING)
6. Target Market Segmentation (TARGET_MARKET_ANALYSIS)

## Success Criteria
- Answer the user's objective completely
- Cite reliable sources
- Avoid hallucinations
- Produce structured outputs
- Be reproducible
- Minimize unnecessary LLM usage
- Handle failures gracefully
- Generate a polished, professional market research report
